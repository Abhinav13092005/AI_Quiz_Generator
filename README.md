# AI Quiz Generator 🤖

A **Generative AI (GenAI) powered quiz generation web application** built using Python, Flask, and Google's Gemini API. It uses GenAI to generate multiple-choice questions on any topic and evaluates the user's quiz score.

## Features
- Generate 5 quiz questions on any topic.
- Four multiple-choice options per question.
- Calculate score and percentage.
- Display feedback based on performance.

## Technologies Used
- Python
- Flask
- Google Gemini API
- HTML
- CSS

## How to Run
1. Install dependencies using `pip install -r requirements.txt`.
2. Add your Gemini API key to a local `.env` file.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
5. ## Live Demo

🚀 **Try the project here:** https://ai-quiz-generator-ykmw.onrender.com

## GenAI Integration

This project uses Google's Gemini API to generate multiple-choice quiz questions dynamically based on the user's chosen topic.

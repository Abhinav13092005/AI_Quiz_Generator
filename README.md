# AI Quiz Generator 🤖

**Live Demo:** https://ai-quiz-generator-ykmw.onrender.com

**GitHub Repository:** https://github.com/Abhinav13092005/AI-Quiz-Generator

A Generative AI (GenAI) powered quiz generation web application built using Python, Flask, and Google's Gemini API.

## Features
- Generate 5 quiz questions on any topic.
- Four multiple-choice options per question.
- Calculate score and percentage.
- Display feedback based on performance.

## Technologies Used

- Python
- Flask
- Generative AI (GenAI)
- Google Gemini API
- HTML5
- CSS3
